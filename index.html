Frequently Asked Questions

How the dashboard reads its data, how stock status is worked out, and what happens to the records you add.

Where does this data come from?

From inventory.csv in the same folder as this page. The file is re-read on every page load, so refreshing picks up any edit you have made to it.

The line under “Inventory Records” always names the source it actually used, so you never have to guess which copy you are looking at.

Why does it sometimes warn about the data source?

Browsers block fetch() on pages opened straight from disk over file://. When that happens the dashboard falls back to a copy of the CSV embedded in the page and tells you so, rather than showing an empty table.

To read the live file instead, serve the folder — for example python -m http.server 8000 — and open http://localhost:8000/.

How is stock status calculated?

It is derived from the row, never stored. Quantity of 0 is Out of Stock; quantity at or below the reorder level is Low Stock; anything above it is In Stock.

Sorting the Status column ranks by urgency rather than alphabetically, so the rows that need attention come first.

Do the KPI cards follow my filters?

No — and that is deliberate. The four cards always describe the whole dataset, so a search or a category filter never makes the network look healthier than it is. The count above the table is the one that tracks your filters.

Are the records I add saved?

Not permanently. Adding or deleting a record changes it for this session only, and a reload restores the file. Edit inventory.csv to make a change stick.

Can I search and sort at the same time?

Yes. Search, the category filter and the column sort are independent and compose freely. Every column header is a button — click it to sort, click again to reverse, and reach it with Tab like any other control.

A row in my CSV did not appear. Why?

Rows with a missing field, a non-numeric quantity or cost, or a SKU that already appears earlier in the file are skipped so bad values never reach the table. The source line reports how many were dropped.

How do I add a warehouse or a category?

Both lists are constants in the page script — CATEGORIES and WAREHOUSES. Add an entry there and it appears in the filter and in both form dropdowns automatically.
